# Daiga Internacional — 公式サイト

コスタリカ・サンホセを拠点とするDaiga Internacionalの紹介サイトです。
`index.html` 1ファイルで完結する静的サイト（CSS・JS・ロゴ画像もすべて内蔵）なので、サーバー側の設定は不要です。

## 内容

- 会社紹介・代表者について
- 事業紹介（不動産・コンサルティング）
- コスタリカ移住・投資コンサルティングの案内（料金表つき）
- 完全オーダーメイドの観光ガイド
- 発信しているふたつのブログの紹介
- 右上の「JA / EN」ボタンで日本語・英語を切り替え可能

## ローカルでの確認方法

`index.html` をダブルクリックするだけでブラウザで開けます。

## 更新のしかた

`index.html` をテキストエディタで開き、該当箇所の文章を書き換えて保存するだけです。
料金・サービス内容・ブログ記事のリンクなどは、それぞれ日本語版（`lang-ja`）・英語版（`lang-en`）のクラスがついた要素として並んでいるので、両方書き換えるようにしてください。
